- Design coordinato, tre modalità tema, palette di navigazione e dashboard con anteprima WebGL.

- Export PDF per intervallo con grafici, confronti, costi, obiettivi e anomalie.
- Build asset riproducibile, migrazioni additive, test API e collaudo Chromium.
